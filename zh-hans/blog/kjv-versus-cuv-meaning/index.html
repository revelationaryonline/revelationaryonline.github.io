KJV 与 CUV 对圣经读者的意义

一节经文在King雅各书版本中让人立刻感到熟悉，而在中文和合版本中却意外地新鲜。这并不意味着一本圣经说的是一件事，而另一本圣经却说的是另一件事。的问题 KJV 与 CUV 含义 通常是关于语言、历史以及读者在自己的社区中听到圣经的方式的问题。

对于一起学习的英语和汉语基督徒来说，这种比较尤其有意义。它帮助我们注意到翻译中的关怀，对一段经文提出更好的问题，并记住神的话语是跨文化的，而不只属于其中一种文化。

KJV 和 CUV 是什么意思

KJV 代表 King 雅各书 Version，这是一本于 1611 年首次出版的英文圣经。几个世纪以来，其庄严的措辞塑造了英语教会生活、赞美诗、讲道和个人奉献。许多读者珍惜它的诗意语言和大声朗读圣经时所带来的连续感。

CUV 通常代表中文联合版。经过众多翻译团队多年的努力，该书于 1919 年出版，成为新教基督徒中使用最广泛的中文圣经。对于许多华语信徒来说，CUV 在敬拜和记忆中的地位类似于《KJV》对于许多英语基督徒的地位。

因此，KJV 与 CUV 并没有描述两个英文版本争夺相同观众的情况。它通常意味着将历史英文译本与历史中文译本进行比较。每一个都是为了帮助人们以他们可以阅读、听到、记忆和分享的语言来接触圣经。

有一个有用的警告。 “CUV”可能是指以繁体或简体中文印刷的版本，读者也可能会遇到诸如修订中文联合版之类的修订版本。如果有人说“CUV”，在从细微的措辞差异中得出结论之前，有必要询问他们使用的是哪种文本和脚本。

KJV 与 CUV 含义：为什么措辞不同

每一个翻译都必须做出选择。希伯来语、阿拉姆语、希腊语、英语和汉语的句子排列方式不同，每个想法的含义也不同。一个翻译可以是忠实的，无需逐字匹配另一个翻译。

KJV 经常使用对现代读者来说听起来过时的英语形式，包括“thou”、“thee”和“hast”等单词。这些词可能很美丽，但它们的含义并不总是显而易见的。例如，古英语中的“let”可以表示“阻碍”，而不是“允许”。采用现代含义的读者可能会在理解更深层次的信息之前误解这节经文。

CUV有其自身的历史质感。它的经典措辞对于中国基督徒来说是高度认可的，并且听起来很正式或文学，尤其是在繁体中文中。这种熟悉感可以使其在敬拜中令人难忘，而新读者可能会从日常言语中不太常见的表达方式上停下来，从而受益匪浅。

句子顺序的差异也是正常的。英语通常通过词序和连接词来标记关系。中国人可能会更简洁地表达这些关系，或者在句子的其他地方强调。当KJV短语比其对应的CUV更长时，或者当CUV似乎以不同的顺序陈述一个想法时，这种差异可能是语言上的而不是神学上的。

翻译历史影响比较

《KJV》是在英国历史上的一个特定时刻制作的，利用了译者可获得的手稿和学术成果。其新约与近代早期常用的希腊文本密切相关。从那时起，学者们研究了许多其他的圣经手稿，现代翻译有时反映了不同的文本决定。

CUV 也是在特定的历史背景下生产的。其翻译团队利用圣经语言学术成果和当时有影响力的翻译，致力于为中文新教教会创作一本共享圣经。它并不是被设计成《KJV》的逐行中文镜像。

当读者比较带有脚注、括号内的短语或措辞略有不同的经文时，这一点很重要。差异可能来自翻译方法、潜在的手稿传统或关于如何最好地表达原始语言的决定。假设熟悉的措辞已被删除，或者较短的措辞意味着段落已被削弱，都是不明智的。

相反，请将这些时刻视为学习的邀请。阅读周围的段落。检查注释是否解释了差异。在将比较作为主要问题之前先问一下这篇文章在教导什么。

意义比一个熟悉的短语更重要

翻译并不仅仅因为它保留了特定的词序而被认为是忠实的。翻译也不会仅仅因为使用当代语言就自动变得更加清晰。忠实的阅读会问翻译是否传达了圣经作者在上下文中所说的内容。

选取一段关于神的圣约、怜悯、公义或国度的经文。一种语言可能使用具有广泛关联的简洁术语，而另一种语言则需要多个单词来传达相同的想法。比较翻译可以揭示这种丰富性，但这两个版本都不应该被视为单独解决每个问题的密码。

最好的比较将两种信念结合在一起：圣经的话语意义深远，明智地阅读它们需要上下文、谦卑和对整个圣经故事的关注。

如何并列学习KJV和CUV

从段落开始，而不是寻找差异。首先阅读一个翻译的完整部分。注意谁在说话、之前发生了什么、重复的话语、命令、承诺以及论证或故事的主要动作。然后阅读其他翻译中的同一部分。

如果短语不同，请询问一些简单的问题。是否存在相同的中心思想？不同的语言能以不同的方式表达这个想法吗？更广泛的章节是否阐明了含义？是否有注释可以识别手稿或翻译问题？这些问题使比较变得建设性而不是焦虑。

大声说出这节经文也有帮助。 KJV 通常使英语中的重复和节奏模式更加明显。 CUV 可以通过中文结构和熟悉的教会语言使短语令人难忘。听到这两种声音可以提醒研究小组，圣经最初主要是通过公众阅读而被接受的，而不仅仅是私人分析。

对于双语家庭、小组或教会，避免将一种语言设为“真正的”圣经，而将另一种语言设为次要版本。邀请每位读者分享他们的发现。讲中文的信徒可能会指出英语读者忽略的重点；讲英语的信徒可能会提出一个问题，鼓励人们更加关注这段经文。当人们仔细倾听而不是仅仅捍卫自己喜欢的措辞时，共同研究就会变得更加有力。

选择当前正确的版本

没有必要在欣赏和理解之间做出选择。 KJV 可能是供记忆、公共阅读或重新连接教会传统语言的珍贵译本。 CUV 可能是读者第一次听到福音、学会祈祷或与家人一起遵循圣经的圣经。

与此同时，难以理解任一版本的读者不应该因为使用更清晰的翻译而感到内疚。理解并不是一个次要的目标。这是专心接受神话语的一部分。将熟悉的版本与用更现代的语言编写的翻译进行比较可以防止我们过快地传递我们认为已经知道的短语。

翻译比较应该让我们回到虔诚的关注，而不是无休止的争论。当 KJV 和 CUV 听起来不同时，请停留足够长的时间询问每个可以帮助你看到什么。阅读更广泛的段落，欢迎其他读者的见解，让共同的理解工作让你更接近说话的神。
